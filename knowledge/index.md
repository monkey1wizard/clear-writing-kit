# Clear Writing Kit knowledge

Read the usage guide for the current environment, then accuracy and the relevant language guide. Local check procedures apply to coding agents. These retrieval documents are not installable skill packages.

## Writing rules and languages

- [Accuracy and clarity](rules/accuracy.md) - Preserve meaning, uncertainty, and scope while making answers clear.
- [United States English](rules/en-US.md) - Apply English writing guidance without losing conditions or uncertainty.
- [臺灣繁體中文](rules/zh-TW.md) - 使用臺灣繁體中文撰寫清楚且保留完整意思的文字。
- [日本語の文章規則](rules/ja-JP.md) - 文書には常体、会話には敬体を使い、意味を正確に伝える。
