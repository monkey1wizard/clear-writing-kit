# References

This is the single reference list for the writing rules in this repository. Entries follow the APA Style 7th edition. Each entry has a stable citation key. The `Sources` section at the end of each rule file maps rules to these keys and names the rules that the project wrote itself.

A citation records that a source informed a rule or defines the behavior of a checker. It does not state that this repository meets a standard. Each entry was checked against its source on October 8, 2026, or on its retrieval date. The `[GoogleDevStyle]`, `[MicrosoftStyle]`, `[FPLG2011]`, and `[JTF2026]` entries were checked on October 10, 2026. Titles link to the cited page.
